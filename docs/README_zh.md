# 仓库中文说明

这是论文修改阶段的私人复现仓库，暂时不能声称为完整公开数据包。

- `data/raw`：用户提供的原始文件，只重命名副本，不修改内容。
- `data/interim`：以后填写逐篇筛选结果和融合层级复核结果。
- `data/processed`：HistCite和VOSviewer已有输出。
- `config`：检索式、软件版本、融合编码规则和VOSviewer参数。
- `manuscript`：当前LaTeX源代码、有效图片和PDF。

当前已明确区分261篇计量分析语料和163篇保留了逐篇融合层级赋值的编码
子集。该子集并非通过前瞻性、随机或代表性抽样获得，因此其类别数量只
作为原工作材料的补充性审计证据，不再用于估计全部261篇的融合层级比例，
也不再作为摘要和结论中的主要发现。其余98篇仍参与计量分析，但未被
事后补造融合层级。现有原始工作表只包含255个题名，与历史WoS快照比对后
已记录7篇漏项；如需声称完整逐篇复现，仍须建立最终261篇编码表。
