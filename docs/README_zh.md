# 仓库中文说明

这是论文修改阶段的公开复现仓库。

- `data/raw`：经过筛选的261条WoS分析输入及其校验信息。
- `data/interim`：筛选记录和融合层级复核模板。
- `data/processed`：HistCite、VOSviewer及融合编码输出。
- `config`：检索式、软件版本、融合编码规则和VOSviewer设置。
- `manuscript`：当前LaTeX源代码和有效图片。

## 261条分析语料

`data/raw/wos/wos_export_screened_261.txt`包含261个唯一WoS编号（UT），与
公开的261行语料清单完全一致。该文件由保留的源导出按UT筛选生成，入选记录
逐条原样复制；原始导出仍保存在作者本地，没有被覆盖。被删除的5条记录包括
3篇中文论文、1篇2026年论文，以及1篇不符合实际深度学习方法范围的2022年
固定卷积核论文。

## VOSviewer设置

`config/vosviewer/evidence`保存两张裁切后的设置截图：一张记录标准化、布局
和聚类参数，另一张记录节点、标签与连线显示参数。这里只报告截图中能够直接
看到的设置，不从截图推断阈值、随机种子或隐藏高级参数。节点数、出现频次和
TLS以论文正文及保留的输出表为准。

关键词图的公开处理链为：261条筛选后WoS输入、相应年份子集、All keywords、
对应的关键词替换表，以及截图中可见的VOSviewer 1.6.20布局、聚类和显示
参数。三份关键词替换表均保留原始内容。

## 融合层级编码

261篇计量分析语料与163篇有存档融合层级赋值的子集是两个不同分析集合。
163篇包括131篇纯特征级、18篇混合级、7篇纯数据级和7篇纯决策级。其余
98篇仍进入文献计量语料，但不参与融合层级比例估计，因此原80.9%不再作为
全部261篇或整个LULC领域的结论。

题名工作表中有255篇；核对7篇候选漏项后补回6篇，另1篇因采用固定且不训练
的卷积核而排除，形成`255+6=261`。补回的6篇没有事后追加融合层级赋值，
因此163篇存档编码总数保持不变。
