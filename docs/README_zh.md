# 仓库中文说明

这是论文修改阶段的私人复现仓库，暂时不能声称为完整公开数据包。

- `data/raw`：用户提供的原始文件，只重命名副本，不修改内容。
- `data/interim`：以后填写逐篇筛选结果和融合层级复核结果。
- `data/processed`：HistCite和VOSviewer已有输出。
- `config`：检索式、软件版本、融合编码规则和VOSviewer参数。
- `manuscript`：当前LaTeX源代码、有效图片和PDF。

当前已明确区分261篇计量分析语料和通过第二阶段内容筛选获得的163篇融合
层级分析子集。作者确认261篇均根据摘要、关键词、数据集和模型描述接受了
筛选；只有能够可靠识别数据级、特征级、决策级或混合融合操作位置的论文
进入融合层级分析。其余98篇仍参与计量分析，但未满足融合层级分析的纳入
条件。现有原始工作表保存了163个赋值，但只包含255个题名，不能作为完整
的261行筛选日志；与历史WoS快照比对后还记录了7篇漏项。
