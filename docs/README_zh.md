# 仓库中文说明

这是论文修改阶段的私人复现仓库，暂时不能声称为完整公开数据包。

- `data/raw`：用户提供的原始文件，只重命名副本，不修改内容。
- `data/interim`：以后填写逐篇筛选结果和融合层级复核结果。
- `data/processed`：HistCite和VOSviewer已有输出。
- `config`：检索式、软件版本、融合编码规则和VOSviewer参数。
- `manuscript`：当前LaTeX源代码、有效图片和PDF。

`config/vosviewer/evidence`只保存两张裁切后的VOSviewer参数面板：一张为
标准化、布局和聚类设置，另一张为节点权重、标签及连线显示设置。公开图中
不包含网络主体、桌面信息或阈值对话框。截图未显示的计数方式、各图阈值、
高级参数和保存的工程文件均不作推断；全文时段仍以正文及现存162项表为准。

两个时间子图的处理链现已单独登记。2021–2025图使用作者确认的
`21-25.txt`、`21-25Keyword.txt`和截图中可见的VOSviewer 1.6.20参数；
2016–2020图使用`16-20keyword.txt`及相同的可见参数。两份关键词替换表均与
仓库公开副本逐字节一致。`21-25.txt`属于受数据库许可约束的本地输入，公开
仓库只登记文件名、记录数和SHA-256，不上传全文记录。2016–2020原始导出
文件待作者后续提供，因此目前不填写文件名、记录数或校验值。截图明确支持
2016–2020最低出现次数为3；2021–2025阈值尚无截图依据，不从39个显示节点
反推。

当前已明确区分261篇计量分析语料和现有工作材料中保存了融合层级赋值的
163篇子集。第二阶段融合内容分析只有在摘要、关键词、数据集和模型描述
能够支持可靠识别数据级、特征级、决策级或混合融合操作时才保留赋值。
现有材料不能证明其余98篇都经过了同等完整且可审计的逐篇判定，因此不把
它们统一表述为“不符合纳入条件”。其中92篇是255题名工作表中的空白行，
另6篇是题名核对时补回、但没有被事后赋予融合类别的计量记录。仓库现已
公开由255个历史工作表题名和6个补回记录组成的261行UT/题名分析语料清单。
该清单只含有限书目信息，不把另行保存的266条WoS后期快照改称为261条。与历史WoS快照
比对后发现7篇候选漏项，其中6篇符合
英文、文献类型、时间范围和实际采用深度学习方法的纳入范围，补回后形成
`255+6=261`篇；另外1篇采用固定且不训练的卷积核，深度学习只作为背景
比较，因此未纳入。6篇补回文献没有被事后赋予融合层级，故原有163篇融合
层级编码及其类别数量保持不变，其余98篇由工作表中的92个空白记录和这6篇
补回文献构成。
