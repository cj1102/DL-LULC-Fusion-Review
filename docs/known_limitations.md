# Known limitations

1. The exact day of the January 2026 retrieval has not been confirmed.
2. The VOSviewer screenshots document visible layout, clustering and display
   controls only; thresholds, random seeds, hidden advanced parameters and saved
   project files are not claimed.
3. The retained thesaurus files include both spelling/abbreviation normalisation
   and broader concept aggregation, so keyword results are interpreted under
   those archived vocabulary rules.
4. Fusion-level assignments are retained for 163 records, not all 261 records;
   the corresponding percentage is therefore not presented as a corpus-wide
   prevalence estimate.
5. The repository preserves reported software outputs and figures but does not
   claim pixel-identical regeneration of every network drawing.
